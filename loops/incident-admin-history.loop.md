- [ ] 詳細頁用白話顯示摘要、影響、時間線、根因、暫時處理、永久修正、預防、驗證證據與相關版本。
- [ ] 事故可建立、更新狀態及追加事件；修改者、時間及改前改後完整留存，不可覆蓋歷史。
- [ ] 可連到相關請求編號與部署版本，但不保存 token、完整 Prompt、完整 Response 或其他敏感內容。
- [ ] 只有管理者可讀寫；一般 Gateway 金鑰與跨隔離範圍存取均被 API 拒絕。
- [ ] 匯入既有 2026-10-21 Gateway 事故，瀏覽器能讀到與文件一致的核心事實。
- [ ] 格式、靜態檢查、資料轉換、API、權限、稽核、前端、瀏覽器與正式站版本讀回全過。

## Trade-off
| 決策 | 選了什麼 | 放棄了什麼 | 為什麼 |
| --- | --- | --- | --- |
| 儲存 | 結構化事故＋不可覆蓋事件 | 直接編輯單篇文件 | 可查、可稽核、可驗證 |
| 請求內容 | 只存編號與安全摘要 | 複製完整內容 | 避免洩漏敏感資料 |
| 隔離 | 系統事故＋可選範圍 | 一律全公司可見 | 同時支援共通與局部事故 |
