# 02 身分、個人憑證與連線

目標：每位使用者以自己的 Gateway 金鑰使用自己選擇的模型帳號，不借用他人權杖。

- 接手既有 identity-groups 工作；檢查現有單一 Anthropic 權杖如何讀取與更新，再設計依使用者與供應來源隔離、儲存、更新、撤銷與失敗關閉。
- 管理者及使用者的權限需清楚；Client 不取得供應商憑證。個人登入由本人完成，不自動登入、不共用帳號；支援本機與遠端 Gateway。
- 驗收：兩個身分各用自己的憑證；交叉使用、未綁定、撤權與更新不得誤用他人憑證，附陰性對照。正式測試只用各自已授權帳號；未有第二人帳號時不能宣稱多人實送通過。
- 外部供應商支援及條款以官方當前文件與實測為準，不把推測當禁令或保證。

狀態 RUNNING；01 已列出圖與程式的初步對照。先確認身分解析、來源設定與既有管理權限的實際接點，設計兩人隔離與舊版單人模式的相容方法，再寫可證明交叉使用會失敗的測試。

工作分支原本少正式版 `d1c29e8`，已以不自動提交的合併接入，Git 無衝突，原未提交檔案保留；合併尚未完成提交。後續須在合併狀態完成實作及必要檢查，不能把未提交合併當成已交付。

已初步加入 `ANTHROPIC_PERSONAL_TOKEN_DIR` 個人模式，Messages 與 OpenAI 格式轉接均在上游請求前依租戶及 user ID 讀個人權杖；缺使用者或權杖回服務不可用，不退回單人權杖。個人模式暫停背景拆解，避免該路徑繞過個人權杖選擇。此為未交付實作：尚無個人權杖管理 API、端到端隔離測試與正式驗收；其他供應商的個人憑證也未實作。保存單元測試 1 項通過；設定驗證在測試之後新增，尚須重新驗證。

新增管理者個人權杖設定及撤銷 API，先確認使用者屬於管理者租戶且啟用，再記操作嘗試；回應不含權杖。編譯及兩項單元測試通過（保存隔離、管理角色權限），293 項未跑。介面真實 HTTP、稽核資料庫、使用者狀態競態與請求端到端均未驗；操作嘗試不等於成功結果，需補結果稽核。不得部署。

新增請求準備前的兩人身分對照：Alice、Bob 各得到自己的權杖，無 user、跨租戶及撤銷後均拒絕；三項個人權杖測試通過。另在供應商請求組裝測試確認個人權杖取代 Gateway 金鑰且保留訂閱必要標頭，該項通過。此為程式內測試，尚未經 HTTP 送到上游，也未補操作結果稽核；其餘測試未跑。

管理操作已加入嘗試後的成功／失敗稽核，三項個人權杖單元測試重新通過。檔案與資料庫不是同一交易：如果檔案變更後稽核寫入失敗，會留下嘗試但沒有結果，回應為失敗；須以真資料庫測試並釐清恢復方式，不能宣稱稽核完整。

隔離 PostgreSQL 配合 Gateway 的 HTTP 路由測試通過：跨租戶使用者回 404、本人設定成功、撤銷成功，資料庫有四筆嘗試及結果稽核。測試首次因查詢誤用不存在的 `created_at` 失敗，修正查詢後通過；296 項未跑。已修正管理介面跨來源設定允許 PUT。這未驗證供應商 HTTP 或稽核寫入故障的恢復；測試容器已停止。

本機模擬供應商實際收到兩個身分各自的 Authorization，測試 1 項通過；這從選取個人權杖測到上游 HTTP，不包含 Gateway 入口認證和真實 Anthropic。個人權杖讀取、更新、撤銷失敗增加不含權杖內容的錯誤紀錄；新增日誌尚待 secrets 檢查。稽核資料庫故障恢復、跨程序併發與其他來源的個人憑證仍未完成。

個人權杖檔操作新增共用檔案鎖，競爭時立即拒絕，不無限等待；同程序以兩個獨立檔案控制代碼驗證鎖被占用時拒絕、釋放後成功，相關三項測試通過。尚未以兩個 OS 程序驗證，也未量測鎖競爭；目前共用同一把鎖，並行請求可能暫時失敗，須改善後才部署。

鎖已縮小為租戶與使用者各自一把，不同使用者不互相拒絕；以獨立 `flock` 程序持有同一把鎖，驗證操作被拒絕、釋放後成功，相關四項測試通過。仍未量測同一使用者的併發請求，鎖競爭會立即回失敗；尚未完成 Gateway 全流程與部署驗收。

讀取改用共享鎖，測試同一使用者可同時讀取、讀取時撤銷被拒絕，釋放後撤銷成功。首次執行 5 項通過、1 項因未設定隔離資料庫失敗；啟動隔離資料庫後重跑 6 項通過、294 項未跑，測試容器已停止。鎖在讀取後即釋放，已取得的權杖可能在撤銷後才送出；必須補上併發撤銷與實際送出之間的契約及測試，不能宣稱立即撤銷。

初步改為從讀取權杖持有共享鎖到上游回應標頭或送出失敗，處理延遲串流時也把鎖交給送出工作；鎖尚在時撤銷會失敗，不能誤稱成功。個人來源選擇與本機模擬上游測試 1 項通過、299 項未跑；這尚未驗證延遲送出及撤銷的真實競態，不能宣稱問題完全修好。初次編譯因過早釋放設定仍被使用而失敗，修正後通過。

新增延遲模擬供應商的 HTTP 測試：上游已接到請求但尚未回標頭時撤銷失敗，收到標頭後撤銷成功，1 項通過、300 項未跑。此測試直接測來源送出與鎖，未經 Gateway 入口或測延遲串流。`./scripts/check.sh gate` 的格式與 clippy 通過，但既有未提交 `loops/agent-platform-decisions.loop.md` 不符合規定，整體檢查失敗；保留原檔，不繞過。個人模式的容器掛載與設定文件仍須補上。

個人模式整合測試增加日誌掃描：兩人成功與未綁定失敗的請求，日誌均未出現 Gateway 金鑰或三個測試權杖；人工加入測試權杖的掃描對照可被偵測。管理 API 回應及稽核內容也未含測試權杖。隔離資料庫執行個人權杖相關 8 項通過、294 項未跑；這不等於完整正式日誌掃描或真實 Client 驗收。
